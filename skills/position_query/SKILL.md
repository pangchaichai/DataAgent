description: |
  查询特定产品、主体或债券的当前持仓信息，返回持仓明细、市值汇总、评级分布等数据。
  适用场景：用户询问持仓明细、查某个产品或主体持有哪些债券、某债券被哪些产品持有。
  触发词：持仓、持有、查询、债券明细、持有什么、买了哪些
---

## 适用场景
用户需要快速查看持仓数据，场景包括：
- "XX产品持有哪些债券？"
- "XX主体当前持仓市值是多少？"
- "查一下各产品对XX集团的敞口"

## 前提条件
- 持仓表（含字段：产品名称、资产名称、资产代码、资产市值_穿透后、外部评级、G06一级分类、限额占用方主体）

## 数据计算规则

### 按产品查询持仓明细
```sql
SELECT
  资产名称, 资产代码,
  ROUND("资产市值_穿透后", 2) AS 市值,
  外部评级, G06一级分类, 剩余期限,
  到期日
FROM holding_table
WHERE 产品名称 = ?
ORDER BY "资产市值_穿透后" DESC
LIMIT 100
```

### 按主体汇总各产品持仓
```sql
SELECT
  产品名称,
  COUNT(DISTINCT 资产代码) AS 品种数,
  ROUND(SUM("资产市值_穿透后"), 2) AS 全穿透合计,
  ROUND(SUM("资产市值_半穿透"), 2) AS 半穿透合计
FROM holding_table
WHERE 限额占用方主体 LIKE '%?%'
GROUP BY 产品名称
ORDER BY 全穿透合计 DESC
LIMIT 50
```

### 汇总统计
```sql
SELECT
  COUNT(DISTINCT 资产代码) AS 总品种数,
  ROUND(SUM("资产市值_穿透后"), 2) AS 总市值,
  COUNT(DISTINCT 产品名称) AS 涉及产品数
FROM holding_table
WHERE 产品名称 = ? -- 或 限额占用方主体 LIKE ?
```

## 输出格式
以表格形式在对话中直接展示，同时提供汇总行。
本 Skill 无报告模板，结果直接展示在聊天界面。

## 注意事项
- 结果超过 50 行时，自动截断并提示"共 N 行，已显示前 50 行，如需完整数据请导出 Excel"
- 市值字段展示时保留2位小数，单位为元（或万元，按上下文判断）

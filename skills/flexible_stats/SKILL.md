## 适用场景
用户需要按照自定义维度进行灵活统计，例如：
- 按资产类型统计某部门的持仓金额
- 按产品类型统计发行份额
- 按销售渠道统计规模分布

## @mention 数据源指定（重要）
本 Skill 支持用户通过 @表名 显式指定数据来源，防止统计口径偏差：
- 用户输入"@持仓_20260515 统计..."时，只在该表中查询
- 未使用 @mention 时，在最新日期的同类型表中查询
- 若用户对统计结果有疑问，引导其使用 @mention 明确数据源

## 执行步骤

### Step 1：解析用户意图
从用户指令中提取：
- 统计维度：按什么分组（资产类型 / 产品类型 / 销售渠道 / 部门 / ...）
- 统计指标：统计什么（金额 / 数量 / 份额 / 占比 / ...）
- 筛选条件：范围限制（某个部门 / 某类产品 / 某段时间 / ...）
- 数据来源：@mention 指定的表，或默认最新表

### Step 2：生成分类统计 SQL
根据解析出的意图，动态生成 GROUP BY 查询。
以下为常见场景的 SQL 模板：

**按资产类型统计持仓金额：**
```sql
SELECT
  G06一级分类 AS 资产类型,
  G06二级分类 AS 资产细类,
  COUNT(DISTINCT 资产代码) AS 持仓品种数,
  ROUND(SUM("资产市值_穿透后") / 10000, 2) AS "持仓金额(万元)"
FROM {target_table}
WHERE {filter_condition}  -- 按部门产品列表或其他条件过滤
GROUP BY G06一级分类, G06二级分类
ORDER BY "持仓金额(万元)" DESC
LIMIT 100
```

**按产品类型统计份额和金额（需净值/产品信息表）：**
```sql
SELECT
  产品类型,  -- 字段名以实际数据表为准
  COUNT(DISTINCT 产品代码) AS 产品数量,
  ROUND(SUM(发行份额) / 100000000, 2) AS "发行份额(亿份)",
  ROUND(SUM(产品规模) / 100000000, 2) AS "规模(亿元)"
FROM {target_table}
WHERE {filter_condition}
GROUP BY 产品类型
ORDER BY "规模(亿元)" DESC
LIMIT 50
```

### Step 3：输出统计结果
以表格形式展示，同时给出合计行和文字摘要。

## 人工确认节点
如果统计结果涉及多个维度或数值较大，询问用户是否需要导出为 Excel 或生成报告。

## 数据口径说明
统计前，自动向用户确认当前使用的数据表和日期，避免口径歧义：
"当前统计使用的数据表为：{table_name}，数据日期：{data_date}，是否正确？"

## 注意事项
- 统计字段名（如"产品类型"、"销售渠道"）以实际加载的数据表字段为准
- 若所需字段在已加载表中不存在，明确告知用户并建议上传对应数据文件
- 灵活统计不保证字段100%匹配，复杂需求建议创建专属 Skill

## 适用场景
用户上传本周理财产品数据源（CSV），需要按产品类型分类生成五份周报 CSV 文件，供业务部门分发使用。

## 前提条件
- 必须上传包含"周报"和"数据源"的 CSV 文件（如"周报-本周数据源.csv"）
- 文件应包含所有产品类型的数据行，由本 Skill 自动筛选

## 执行步骤

### Step 1：读取数据源
使用 `profile_table` 查看数据源表结构，确认关键字段存在（产品标签、组合代码等）。

### Step 3：提供下载

将生成的五个 CSV 文件通过 render_report 输出，并告知用户各文件的行数。

## 输出格式
- 5 个 CSV 文件：周报-机构专户产品.csv / 周报-其他产品.csv / 周报-现金替代产品.csv / 周报-长封闭产品.csv / 周报-重点产品.csv
- 使用 UTF-8 编码，逗号分隔，标准 CSV 引号规则
- 若某筛选条件下无匹配产品，生成仅含列头的空 CSV（一行表头）

## 字段映射说明
- 列名 `上周规模` → 数据源列 `期初规模`（以此类推：上周净值→期初净值，上周杠杆率→期初杠杆率，上周久期→期初久期）
- 列名 `业绩基准` → 数据源列 `业绩基准值`
- 列名 `是否重点产品` → 数据源列 `是否重点产品（固收）`
- 空列：部分模板中"是否达基"后保留一列空值（列名为空字符串，值也为空）

## 注意事项
- 数字中的千分位逗号（如 "1,234.56"）按原始格式保留，不做转换
- 若数据源中缺失映射所需的某字段，该列留空，不影响其他列的输出
- 本 Skill 执行严格字段映射，不进行任何数值计算或格式转换

## 适用场景
用户需要生成某个理财产品的标准运作报告，报告内容包括产品基本信息、净值表现、资产配置分析、风险指标分析和管理人意见。

## 前提条件
执行本 Skill 前，必须已加载以下数据表：
- **净值表**（nav_YYYYMMDD）：含产品名称、单位净值、各期收益率、最大回撤、久期、杠杆率
- **持仓表**（holding_YYYYMMDD）：含产品名称、资产分类、市值、外部评级

## 执行参数
从用户输入中提取：
- `product_name`：产品名称（必填，从净值表或持仓表的产品名称字段获取）
- `report_period`：报告期间（选填，格式"YYYY年MM月DD日至YYYY年MM月DD日"，默认使用数据最新日期）

## 数据计算规则（LLM 严格按此生成 SQL，不得自行估算数值）

### Step 1：产品基本信息 + 净值指标
```sql
SELECT
  产品名称,
  估值日期,
  单位净值,
  "当前周期年化收益率(%)",
  "近1月年化收益率(%)",
  "近3月年化收益率(%)",
  "本季度最大回撤(%)",
  "久期(年)",
  杠杆率,
  "业绩比较基准(%)"
FROM nav_table
WHERE 产品名称 = ?
ORDER BY 估值日期 DESC
LIMIT 1
```

### Step 2：资产结构分布
```sql
SELECT
  G06一级分类 AS 资产类别,
  ROUND(SUM("资产市值_穿透后") /
        SUM(SUM("资产市值_穿透后")) OVER() * 100, 2) AS 占比
FROM holding_table
WHERE 产品名称 = ?
GROUP BY G06一级分类
ORDER BY 占比 DESC
LIMIT 20
```

### Step 3：前十大持仓
```sql
SELECT
  ROW_NUMBER() OVER (ORDER BY "资产市值_穿透后" DESC) AS 序号,
  资产名称 AS 证券名称,
  ROUND("资产市值_穿透后", 2) AS "市值(元)",
  ROUND("资产市值_穿透后" /
        SUM("资产市值_穿透后") OVER() * 100, 2) AS "占净资产比(%)"
FROM holding_table
WHERE 产品名称 = ?
ORDER BY "资产市值_穿透后" DESC
LIMIT 10
```

### Step 4：信用评级分布
```sql
SELECT
  CASE
    WHEN 外部评级 = 'AAA' THEN 'AAA'
    WHEN 外部评级 = 'AA+' THEN 'AA+'
    WHEN 外部评级 IN ('AA') THEN 'AA'
    WHEN 外部评级 IS NULL OR 外部评级 = '' THEN '无评级'
    ELSE 'AA-及以下'
  END AS 评级区间,
  ROUND(SUM("资产市值_穿透后") /
        SUM(SUM("资产市值_穿透后")) OVER() * 100, 2) AS 占比
FROM holding_table
WHERE 产品名称 = ?
GROUP BY 评级区间
ORDER BY 占比 DESC
LIMIT 10
```

## 人工确认节点
计算完 Step 1-4 的所有数值后，**必须**将以下数据展示给用户确认，用户点击确认后才能继续生成报告：
- 产品净值、年化收益率
- 资产结构占比表
- 前十大持仓表
- 信用评级分布

## 报告生成规则
- 模板文件：`template.md.j2`（同目录）
- **数值段落**（🔒固定 + 📊数据更新）：直接填充精确计算值，不调用 LLM
- **文字段落**（✍️灵活）：调用企业内网 LLM 生成，输入为数值摘要，输出为文字
  - 段落2.1 市场环境回顾：LLM 根据报告期间生成市场回顾
  - 段落5 管理人意见：LLM 根据产品表现生成管理人意见
- **禁止**：LLM 在文字段落中自行编造或估算数字

## 注意事项
- 如果净值表中找不到指定产品，停止执行并提示用户检查产品名称
- 如果持仓表中没有该产品数据，资产结构和持仓部分注明"数据暂缺"
- 报告输出路径：`data/outputs/运作报告_{产品名称}_{日期}.md`

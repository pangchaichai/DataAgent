# DataAgent 快速上手指南

> **面向**：投资业务人员 ｜ **预计阅读**：5 分钟 ｜ **版本**：v3.4

---

## 一、DataAgent 是什么

一个**本地运行的 AI 数据分析助手**。你只需用中文对话，就能查询数据、生成报告、监控合规。

核心特点：**数据不出内网、计算结果可审计、不要求你会写代码**。

---

## 二、安装与首次启动

### 前提
- Windows 10/11，4GB 以上内存
- 已安装 **Python 3.11**（[下载](https://www.python.org/downloads/)，安装时勾选「Add Python to PATH」）

### 安装

```
① 解压 DataAgent-v3.4.zip 到任意目录
② 双击 setup.bat（约 1-2 分钟，仅首次需要）
③ 编辑 DataAgent\config.yaml，配置 LLM
④ 双击 run.bat 启动
```

### 配置 LLM（选一种）

编辑 `DataAgent\config.yaml`：

```yaml
# 企业内网（推荐）
llm:
  sql_gen:
    primary: enterprise_internal
  enterprise_internal:
    url: http://[内网地址]:8081/v1
    model: [模型名称]

# 或 DeepSeek（需 API Key）
llm:
  sql_gen:
    primary: deepseek
  deepseek:
    api_key: sk-xxxxxxxx
    model: deepseek-chat
```

## 四、三步完成一次分析

### 第 1 步：上传数据

1. 切换到 **📊 数据** 页面
2. 拖拽文件到上传区域，或点击选择文件
3. 弹出确认窗口 → 核对表类型和预览 → 点击「确认导入」

> 支持格式：`.csv` / `.xlsx` / `.xls`。系统会自动识别编码（UTF-8/GBK）和表类型（持仓/净值/评级）。

### 第 2 步：提问

切换到 **💬 对话** 页面，用中文提问：

| 你想知道什么 | 可以这样问 |
|-------------|-----------|
| 查询持仓明细 | 「XX产品目前持有哪些债券？」 |
| 统计汇总 | 「按产品分组统计持仓市值」 |
| 筛选条件 | 「外部评级低于 AA 的持仓有哪些？」 |
| 对比分析 | 「对比 0515 和 0501 两期持仓的变化」 |
| 生成图表 | 「帮我画一张产品市值占比饼图」 |

> 提示：有多张表时，用 `@表名` 指定查询对象，如 `@持仓_0515 查询集中度`

### 第 3 步：查看结果

AI 会以表格、图表或文字形式返回结果。表格下方有：
- **📊 图表** 按钮 — 自动生成柱/饼/折线图
- **📥 导出 Word** 按钮 — 保存为 Word 文档

## 五、一键技能（Skills）

Skills 是预设的分析模板，帮你保证口径正确、执行一致。

### 在「📋 规则」页面可以看到：

| 技能 | 做什么 | 触发方式 |
|------|--------|---------|
| 🛡 集中度监控 | 主体/单券集中度检查，自动超标告警 | 输入「检查今天的集中度」 |
| 📈 净值报告 | 产品净值分析（收益率、回撤等） | 输入「生成净值报告」 |
| 🤝 参谈要点 | 拜访客户前的持仓/评级/行业分析 | 输入「帮我准备拜访 XX 的参谈材料」 |
| 🔄 持仓对比 | 两期持仓增减变动分析 | 输入「对比两期持仓变化」 |
| 📊 理财周报 | 批量生成理财周报 | 先上传周报数据源 |

> 固化计算类技能（带 🛡 标记）使用预审公式，结果不经 AI 中间处理，**可审计**。

## 六、图表与报告导出

### 生成图表
查询结果下方点「📊 图表」→ 自动生成，支持切换柱状图/饼图/折线图。

### 导出 Word
分析完成后，消息底部点「📥 Word 导出」→ 保存至 `data/outputs/` 目录。

### 联网搜索
对话中可以直接问：「搜索一下 XX 集团最新的信用评级变化」

## 七、常见问题

| 问题 | 解决方法 |
|------|---------|
| 上传 CSV 出现乱码 | 用 Excel 重新保存为「CSV UTF-8（逗号分隔）」|
| 查询不到想要的表 | 用 `@` 符号 + 表名指定（在数据页面可查看已加载表名） |
| AI 回复"表名不存在" | 表名需完全一致（含日期后缀），在数据页面复制准确表名 |
| 报告文字显示"内网服务暂不可用" | 数值部分仍然正确，文字说明可稍后补充 |
| 如何配置定时自动检查 | 请管理员在 `config.yaml` 中开启 `scheduler.enabled: true` |

## 八、数据安全须知

| 场景 | 安全性 |
|------|--------|
| 原始数据文件 | ✅ 全部存储在本地 `data/` 目录 |
| 合规计算（集中度、净值等） | ✅ 全本地执行，不经过 AI |
| SQL 查询 | ⚙️ 优先走内网 LLM |
| 报告文字生成 | ⚙️ 仅走内网 LLM |
| 审计日志 | ✅ 自动记录，含防篡改指纹 |

> 详见 `docs/user-guide.md` 获取完整说明。

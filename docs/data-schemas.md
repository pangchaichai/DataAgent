# DataAgent 数据表 Schema 定义

> 本文档定义了 DataAgent 已知数据表的结构和字段说明。
> 这是 LLM 生成 SQL 的重要依据，也是 skills/ 中引用字段名的权威来源。

---

## 一、表间关联关系

```
持仓表 ──(产品名称)──> 净值表
持仓表 ──(资产代码/资产名称)──> 债券评级表
持仓表 ──(限额占用方主体)──> 主体评级表

注意：
- 持仓表与净值表通过"产品名称"关联（字符串精确匹配）
- 持仓表与主体评级表通过"限额占用方主体"关联（需模糊匹配或归一化处理）
- 历史评级数据需通过多期文件叠加（按 date_tag 区分）
```

---

## 二、持仓产品管理表（holding）

**文件示例**：`持仓产品管理-2026-05-15.csv`、`Sam底层资产持仓及债券信息表260507.csv`
**编码**：GB18030（旧版）或 UTF-8（新版），**必须 chardet 自动检测**
**加载表名建议**：`holding_YYYYMMDD`

### 核心字段（优先注入 LLM 上下文）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 持仓日期 | date | 数据日期 |
| 产品名称 | str | 理财产品名称，关联净值表 |
| 资产代码 | str | 债券/资产唯一代码 |
| 资产名称 | str | 债券/资产名称 |
| `资产市值_穿透后` | float | 穿透后市值（含千分位逗号，加载时处理） |
| `资产市值_半穿透` | float | 半穿透市值 |
| 外部评级 | str | 外部信用评级（AAA/AA+/AA/AA-等） |
| G06一级分类 | str | 资产大类（债券/现金/存单等） |
| G06二级分类 | str | 资产细分类别 |
| 剩余期限 | float | 剩余到期期限（年），用于期限分层 |
| 票面利率 | float | 债券票面利率(%) |
| 限额占用方主体 | str | 对应的信用主体名称，关联主体评级表 |
| 起息日 | date | 债券起息日期 |
| 到期日 | date | 债券到期日期 |
| 是否上市 | str | 是/否 |

### 按需字段（用户问到相关问题时注入）
- 担保人、担保方式、城投平台级别、行业分类、所属省份、所属地市

### 数值处理规则
```python
# 市值字段含千分位，加载时必须处理
numeric_cols = ['资产市值_穿透后', '资产市值_半穿透', '票面利率', '剩余期限']
for col in numeric_cols:
    if col in df.columns:
        df[col] = pd.to_numeric(
            df[col].astype(str).str.replace(',', ''), errors='coerce'
        )
```

## 三、主体评级表（rating_entity）

**文件示例**：`Sam主体评级结果20260525.csv`
**编码**：UTF-8
**加载表名建议**：`rating_entity_YYYYMMDD`

### 核心字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 主体名称 | str | 企业/发行人名称，关联持仓表限额占用方主体 |
| 内部评级结果 | str | 内部信用评级 |
| 预警等级 | str | 风险预警级别 |
| 理财限额 | float | 理财业务总限额（元） |
| 已占用限额 | float | 当前已使用限额（元） |
| 剩余可用限额 | float | 理财限额 - 已占用限额 |
| 理财限额_2Y | float | 2年期限额 |
| 理财限额_3Y | float | 3年期限额 |
| 理财限额_5Y | float | 5年期限额 |
| 品种（信用政策） | str | 准入品种说明 |
| 评级有效期 | date | 当前评级有效截止日期 |

### 关键说明
- **剩余可用限额**已在 CSV 中直接提供，无需自行计算
- 历史评级（23年末/24年末）需多期文件叠加，或用户手动补充
- 集团系汇总时：将多个主体的限额合计，剩余可用限额取各主体加总

## 六、集团系配置（groups.yaml）

```yaml
# groups.yaml 示例
象屿系:
  - 象屿集团
  - 象屿股份
  - 象屿金象控股
  - 象屿地产集团

建发系:
  - 建发集团
  - 建发股份
  - 建发房地产集团
  - 联发集团

国贸系:
  - 厦门国贸集团
  - 国贸股份
  - 国贸地产
```

集团系汇总逻辑：
1. 从 groups.yaml 获取主体名称列表
2. 在主体评级表中按名称列表过滤（精确匹配或模糊匹配）
3. 汇总各主体限额、持仓数据，生成合计行

## 七、多期数据文件管理规范

同类文件按日期存储，支持历史追溯：

```
data/uploads/
├── holding/
│   ├── 持仓_20260515.csv    ← 命名规范：类型_YYYYMMDD.csv
│   ├── 持仓_20260501.csv
│   └── 持仓_20251231.csv    ← 年末数据手动上传保留
├── rating_entity/
│   ├── 主体评级_20260525.csv
│   └── 主体评级_20251231.csv   ← 用于历史评级对比
├── rating_bond/
│   └── 债券评级_20260525.csv
└── nav/
    └── 净值_20260514.csv
```

加载时指定 date_tag：
```python
data_loader.load_file("holding/持仓_20260515.csv", "holding_20260515", date_tag="20260515")
```

# DataAgent 使用说明

> **面向对象**：投资业务人员（无需技术背景）
> **最后更新**：2026-06-14
> **版本**：v2.0

---

## 一、DataAgent 是什么

DataAgent 是一个本地运行的**自然语言数据分析助手**，专为资管业务设计。

**你可以做什么**：
- 上传持仓 CSV、净值表、评级表等业务数据
- 用中文提问，像和同事对话一样查询数据
- 一键生成合规监控报告、运作报告、参谈要点
- 设置定时任务，自动监控集中度超标

**为什么数字值得信赖**：
- 合规计算（集中度、净值等）使用固化公式，不依赖 AI 估算
- 每次计算自动记录数据来源、公式版本、审计日志
- 所有计算在本地执行，数据不出内网

---

## 二、启动软件

### Windows（生产环境）
1. 解压 `DataAgent-v2.0-beta1.zip`
2. 双击运行 `run.bat`（首次运行需先执行 `setup.bat`）
3. 等待约 3 秒，DataAgent 窗口自动弹出

### macOS / Linux（开发环境）
```bash
python main.py
```
软件会在默认浏览器中打开（效果与 Windows 窗口相同）。

## 四、上传数据

### 方法 1：拖拽上传
将 CSV 文件直接拖入聊天区，松开即开始上传。

### 方法 2：点击上传按钮
点击输入框左侧的 📎 图标，选择文件。

### 支持的文件格式
| 格式 | 用途 |
|------|------|
| `.csv` | 持仓表、净值表、评级表（支持 GB18030/GBK/UTF-8 编码自动识别） |
| `.xlsx` / `.xls` | Excel 文件 |
| `.docx` | Word 文档（供 AI 参考） |
| `.pdf` | PDF 文档（供 AI 参考） |
| `.txt` | 文本文件 |

### 上传确认弹窗
上传后会弹出确认窗口，显示：
- 识别到的编码、行数、列数
- 识别到的数据类型（持仓表/净值表/评级表等）
- 日期标签（从文件名中自动提取）

确认无误后点击「确认导入」，数据才会正式入库。

### 查看已加载数据
成功上传后，左侧边栏「已加载数据表」区域会出现表名。
点击表名可查看数据结构（字段列表和样本数据）。

## 五、查询数据

### 直接提问
上传持仓 CSV 后，可直接输入问题：

```
查询净值低于 1.0 的产品有哪些？

帮我统计各产品的债券持仓市值，按市值排序

XX 产品目前持有哪些评级为 AA 以下的债券？
```

### 指定表格查询（@mention）
当已加载多张表时，可用 `@表名` 指定要查询的表：

```
@持仓_0515 查询所有穿透后市值超过 5000 万的持仓
@净值_0515 和 @净值_0501 对比两期净值变化
```

**注意**：`@表名` 中表名不含空格，需与侧边栏显示的表名完全匹配。

## 六、使用分析技能（Skills）

Skills 是预设的分析场景，确保口径正确、可重复执行。

### 查看可用技能
左侧边栏「分析技能」区域列出所有可用技能，点击即可启动。

### 主要技能说明

#### 1. 集中度监控（concentration_monitor）
监控单一主体/单券集中度，与合规阈值对比，自动告警。

**触发方式**：
- 点击侧边栏「集中度监控」
- 或输入：`帮我检查今天的集中度`、`查一下有没有超标的`

**需要的数据**：持仓表（含穿透后市值字段）

**输出**：
- 主体集中度排名表（含是否超标标记）
- 单券集中度列表
- 集团系合并计算结果
- 合规审计记录（自动写入，可随时追溯）

#### 2. 参谈要点（meeting_report）
生成拜访前的参谈材料，包含主体持仓、评级、行业情况。

**触发方式**：
- 输入：`帮我准备拜访 XX 的参谈要点`
- 或：`生成 XX 集团的参谈材料`

**需要的数据**：持仓表 + 评级表（可选）

**输出**：Markdown 格式参谈要点，可直接复制或导出 Word

#### 3. 净值报告（fund_nav_report）
生成产品净值分析报告，含收益率、最大回撤、夏普比率等指标。

**触发方式**：
- 输入：`帮我生成净值报告`
- 或：`分析一下各产品净值表现`

**需要的数据**：净值表（日期 + 产品名称 + 净值列）

#### 4. 持仓变动对比（position_diff）
对比两期持仓，找出新增、退出、增减仓的债券。

**触发方式**：
```
对比 0515 和 0501 的持仓变化
上周和本周持仓变动了哪些
```

**需要的数据**：两期持仓表（上传时确保日期标签不同）

#### 5. 理财周报（weekly_report_generator）
批量生成理财产品周报，支持多种报告模板。

**需要的数据**：周报数据源 CSV（格式见数据字典）

## 七、图表功能

查询返回数据表后，结果下方会出现「📊 图表」按钮。

**支持的图表类型**：
- 柱状图：对比多个产品/主体
- 折线图：展示趋势变化
- 饼图：展示占比分布
- 散点图：展示相关性

点击「图表」按钮后，系统会根据数据类型自动推荐合适的图表，也可手动切换类型。

## 八、导出报告

### 导出 Word 文档
分析报告生成后，消息底部会出现「📥 导出 Word」按钮。
点击后文件保存到 `data/outputs/` 目录。

### 联网搜索结合分析
可以结合联网搜索获取最新市场信息：
```

```

## 九、设置说明

点击左侧边栏底部的「⚙️ 设置」打开设置面板。

### LLM 配置
| 设置项 | 说明 |
|--------|------|
| SQL 生成（主要）| 优先使用企业内网 LLM，保护商业敏感信息 |
| SQL 生成（备用）| 内网不可用时使用 DeepSeek（需合规确认） |
| 报告文字生成 | 仅走内网 LLM，确保数据不出内网 |

**重要**：若无内网 LLM，仅配置 DeepSeek 也可正常使用查询功能。

### 工作目录
配置本地工作目录后，软件每次启动自动扫描目录内的 CSV 文件，
无需手动上传，适合数据文件固定存放的场景。

## 十、集团系管理

点击左侧边栏「🏢 集团系设置」管理主体的集团关系。

**用途**：计算集中度时，同一集团的多个主体合并计算，避免监管套利。

**操作**：
1. 点击「+ 新建集团」
2. 填写集团名称（如：象屿集团）
3. 添加成员（如：象屿股份、象屿金属、厦门象屿等）
4. 保存后，集中度监控自动使用集团合并口径

## 十一、定时任务

> 注意：定时任务需在 `config.yaml` 中配置并启用 `scheduler.enabled: true`

定时任务支持每日自动执行集中度监控，发现超标时推送系统通知（Windows toast）。

**配置示例**（在 `config.yaml` 中）：
```yaml
scheduler:
  enabled: true
  tasks:
    - name: 集中度每日监控
      skill: concentration_monitor
      time: "09:00"
      notify_on_alert: true
```

## 十二、常见问题

### Q：上传 CSV 出现乱码怎么办？
系统支持 UTF-8 / GB18030 / GBK 自动识别。若仍乱码：
- 用 Excel 重新保存为「CSV UTF-8（逗号分隔）」格式

### Q：查询结果显示"表名不存在"？
检查 `@表名` 中的名称是否与左侧边栏完全一致（含日期后缀）。

### Q：AI 生成的数字和系统不一样？
合规相关数字（集中度、净值指标）由固化计算模块生成，不经 AI 处理。
若发现差异，请联系管理员检查数据字典口径配置。

### Q：报告文字显示"内网 AI 服务暂不可用"？
这表示报告文字生成（需内网 LLM）暂时不可用。
系统已生成数值报告，文字说明部分需稍后补充或手动填写。

### Q：如何查看历史对话？
左侧边栏顶部显示当前会话，刷新页面可开始新对话。
历史会话记录保存在 `data/sessions/` 目录。

### Q：合规审计日志在哪里？
所有合规计算事件自动记录在 `data/compliance_audit/` 目录，
按日期组织的 JSONL 文件，支持事后追溯。

### Q：运行日志在哪里看？
软件运行日志在 `data/logs/` 目录，按天分文件存储。
也可在设置面板「日志」选项卡中在线查看（支持按级别过滤）。

## 十三、数据安全说明

| 场景 | 处理方式 |
|------|---------|
| 数据文件 | 全部本地存储，不上传至云端 |
| SQL 查询生成 | 优先走企业内网 LLM，不传实际数据值 |
| 报告文字生成 | 仅走内网 LLM，禁止 fallback 到外部 |
| 合规计算 | 全本地执行，零 LLM 调用 |
| 审计日志 | 含 MD5 指纹防篡改，本地保存 |
